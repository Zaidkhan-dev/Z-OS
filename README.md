# 🌌 Z-OS

**Z-OS** is a sleek, interactive **web-based operating system interface** developed by me — inspired by Apple's latest **liquid glass design** aesthetics. It’s not a full OS, but rather a visually rich and fun project that reimagines the desktop experience in the browser.

> ✨ Powered by web technologies. Styled with passion. Crafted for creativity.

![image alt] (https://github.com/Zaidkhan-dev/Z-OS/blob/cb34ff0c87e47df1080f3b49203229094b7ce919/Screenshot_20250626-180802.Chrome~2.png)

## 🚀 Features

🪨✂️📄 **3D Rock-Paper-Scissors Game**  
Challenge the computer in a smooth, animated 3D environment.

📝 **Notepad**  
Quickly jot down your thoughts or code snippets in a clean and responsive notepad interface.

🧮 **Calculator**  
A simple, elegant calculator built for fast arithmetic and a touch of glassy design.

🕒 **Live Clock**  
Real-time clock widget that keeps your Z-OS session timely.

🔗 **Gemini AI Shortcut**  
Direct access to Gemini AI — just one click away.

🌐 **Custom Google Page**  
A personalized Google-style search interface with a Z-OS twist.

🎨 **Z-OS Paint**  
A minimal but functional paint app to sketch, doodle, or test your drawing skills right in the browser.

## 🧊 Design Philosophy

Z-OS blends the **fluid beauty of Apple’s liquid glass** UI style with the flexibility and accessibility of the web. Every element is tuned for a soft glow, translucency, and immersive interaction — giving users a feel of a lightweight OS experience without installing anything.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (with backdrop-filter, blur effects)
- **JavaScript**
- Fully client-side, no backend required.
